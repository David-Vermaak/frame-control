Reporting a bug?

The server log helps most: in the app, choose Frame → Show Server Log and paste the last few lines into Details.

Prefer GitHub?

You can open an issue there directly. First-time issues are closed until a maintainer reviews them; see CONTRIBUTING.md. This form skips that queue.
